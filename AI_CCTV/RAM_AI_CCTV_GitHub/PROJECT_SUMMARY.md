# Project Summary

**Project:** RAM AI CCTV  
**Domain:** AI / Computer Vision / Edge Surveillance  
**Goal:** Transform CCTV from passive recording into event-aware, queryable and self-monitoring surveillance intelligence.

**Core technologies:** Python, OpenCV, NumPy, SQLite, REST API, SHA-256, optional YOLO.

**Resume value:** Demonstrates computer vision, backend integration, event processing, local AI architecture, API design, privacy-aware reasoning, and real-world system thinking.
