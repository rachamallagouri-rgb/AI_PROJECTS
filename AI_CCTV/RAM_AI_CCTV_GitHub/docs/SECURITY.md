# Security & Privacy Notes

- Never commit real CCTV credentials or API keys.
- Never upload private face-enrollment images to a public repository.
- Keep generated recordings and evidence outside Git.
- Use `RAM_AI_API_KEY` before exposing the REST API to a LAN.
- Production deployments should use TLS, authentication, authorization, encrypted storage, audit logging, and retention controls.
- AI outputs should be treated as decision-support evidence, not legal conclusions.
