# Features

## Implemented in Prototype
- Camera/video/RTSP source support
- Motion detection
- Person detection
- Optional YOLO object detection
- Face enrollment/recognition readiness
- Event recording
- Camera health metrics
- SQLite event storage
- Evidence file hashing
- Natural-language-style event query interface
- REST endpoints for RAM AI app
- Live MJPEG stream
- Optional webhook/Telegram alerts
- Retention cleanup
- Feedback-driven sensitivity tuning

## Production Extensions
- Role-based authentication
- TLS/HTTPS
- Mobile push notifications
- Stronger face embeddings
- Object tracking across frames
- Multi-camera re-identification
- Encrypted evidence storage
- Signed capture-time evidence
- Production database
- Scalable edge/cloud deployment
